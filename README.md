# Try the Look - 360° Interactive WebGL Streetwear Showcase

A 3D 360-degree interactive streetwear lookbook experience powered by Three.js and WebGL.

## Features
- 360° cylindrical orbit with billboard camera tracking.
- Interactive drag-to-rotate and auto-rotation with play/pause controls.
- Dynamic sidebar product breakdown with bundle pricing.
- Complete head-to-toe full body models with natural floor drop shadows.

## Getting Started
Simply open index.html in any modern web browser or serve it using any HTTP server:
`ash
